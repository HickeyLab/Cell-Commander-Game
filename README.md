# Cell-Commander-Game

Cell Commander is a browser-based strategy game developed by the Hickey Lab to introduce students and the public to the science of cancer immunotherapy. Players build and deploy an immune-cell army against a simulated tumor, each cell type finding and engaging its target the way it does in the body. Developed as part of the lab's K-12 science outreach efforts, the game is grounded in the same kind of biologically-based agent models the lab develops and publishes in peer-reviewed research, rather than in illustrative simplification alone. Cell Commander is intended for demonstrative purposes only: while real biological principles underlie its mechanics, it does not aim for full biological fidelity, and the lab's actual research simulations are considerably more complex and more faithful to the underlying biology. Cell Commander is freely available and runs directly in any web browser, with the full source code hosted on GitHub: HickeyLab/Cell-Commander-Game. 

How to Load It
First, click the “cell-commander-game.html” file in the Github repository, then in the upper right corner where the code begins click “Download raw file”. Once your file is downloaded, click “Open file” to begin playing! 🙂

Alternatively, you can use the link: https://cellcommander.netlify.app. 

To Learn More
The full-source code, the underlying agent based simulation, and the lab’s design documentation is freely available and downloadable in the ZIP file titled “More Information on Cell Commander.zip” for anyone who’s curious about how the game works.
