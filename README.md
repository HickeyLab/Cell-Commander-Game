# Cell-Commander-Game
Cell Commander is a browser-based strategy game developed by the Hickey Lab to introduce students and the public to the science of cancer immunotherapy. Players build and deploy an immune-cell army against a simulated tumor, each cell type finding and engaging its target the way it does in the body. Developed as part of the lab's K-12 science outreach efforts, the game runs on the same biologically-based agent models the lab develops and publishes in peer-reviewed research, rather than on illustrative simplification alone. Cell Commander is freely available and runs directly in any web browser, with the full source code hosted on GitHub: HickeyLab/Cell-Commander-Game. 

How to Load It
Download the “Cell Commander” file then double-click the downloaded file to launch it.🙂
